# Dedicated Thai coffee illustrations

Ten original illustrations created with the built-in image generation tool for thai-coffee.html. Website assets are the ten named WebP files in this folder; original generation files are retained locally. Transparent edges are preserved. These regional scenes are artistic interpretations, not documentary images of specific farms. The existing Thai farm hero is retained.
